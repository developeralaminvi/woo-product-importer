# Alamin Product Importer – URL Import for WooCommerce

Import a product catalog into WooCommerce from Shopify and WooCommerce URLs.

Official plugin page: https://devalamin.me/alamin-product-importer/

See readme.txt for installation, features, limitations, privacy disclosures, and release history.

## Development

PHP, CSS, and JavaScript sources are included directly. No compilation step is required.

Main file: alamin-product-importer.php
Text domain and distribution folder: alamin-product-importer

The plugin creates simple products. It does not convert currency, synchronize stock, or migrate orders and customers.
